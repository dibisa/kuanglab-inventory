Method. Minimizes ‖Kf − y‖² + α‖f‖² with f ≥ 0. The kernel is compressed by SVD, the problem is solved in its dual with Newton's method, and α is set by the Butler–Reeds–Dawson rule (Venkataramanan, Song & Hürlimann, IEEE Trans. Signal Process. 50, 1017, 2002; Butler, Reeds & Dawson, SIAM J. Numer. Anal. 18, 381, 1981). This is the same approach osilap uses. The code here is an independent implementation, not osilap's.

Distribution values are amplitudes per grid point in the units of y, so Σf plus the baseline reproduces the signal. Changing the grid density changes the height of each point but not the peak areas.
